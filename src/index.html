Security

Manage site permissions, site security, and preset security options

SitePermissionAction
Force HTTPS

Force all sites to send requests via HTTPS, which is significantly more secure and better than HTTP.

Allow Saving to IndexedDB

Allow the sites you visit to save data to the browser's IndexedDB, or local storage. Disabling this will not allow sites to save user data and may act like you've never visited before.

Allow Downloading

Allow sites to download files to your computer. You will still always be notified and prompted if a site tries to download a file.

Developer

Manage Electron DevTools, browser/network logs, imported proxies, and more

Enable Electron DevTools

The entire browser's developer console at your fingertips, based on Chromium DevTools. You should never disable this, especially if you have MCP clients as they won't be able to access the console if this is off.

Enable Eruda Console

Eruda is a lightweight console similar to Chromium DevTools designed for mobile devices. Great if you're developing on lower-end devices. There is no MCP support for Eruda.

Enable Logging

Enable logging of network activity via the browser, DevTools console logs, performance logs, and the app's logs.

MCP/Server

Set up AI coding agents that can control and test your websites in the Proxy Development Toolkit

Enable MCP Server

Start a local Model Context Protocol server so Cursor, Claude, Codex, and other agents can attach to this running app over loopback HTTP.

Launch MCP on Startup

The MCP server will be started when the system starts so that your agent is always able to connect, even without the app opened.

Allow Control Tools

When enabled, agents can start sessions, navigate, and open Inspect. When disabled, agents can only read status, screenshots, and logs.

If you change the port or token while the server is running, save settings to restart it with the new values.

Updates

Update Scramjet using Continuous Build

The app will check for pre-release Scramjet updates instead of searching for latest releases. The continuous build is always subject to change and can have bugs and glitches that the latest stable build won't have, so it is recommended you don't enable this unless you are planning on contributing to Scramjet's current code or plan ahead for future releases.

Prefer Pre-Release Updates for App

Updates the Proxy Development Toolkit using pre-release builds instead. These builds are always subject to change and can have bugs and glitches the stable build won't have.

Prefer Pre-Release Updates for Transport Methods

Updates transport methods using pre-release builds instead. These builds are always subject to change and can have bugs and glitches the stable build won't have.

Compile App Updates from Source

New updates or commits are auto-downloaded and compiled from source instead of using a pre-compiled build. This is not recommended as it takes significantly longer than installing pre-compiled builds and is a very CPU-heavy task.
